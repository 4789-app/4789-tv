# External font license provenance

Audited 2026-09-04. Scope: every `.ttf` in `App/FourSevenEightNine/Resources/Fonts/`, which is an external asset input to the TV build. Font files are unmodified by this license audit. SHA-256 identifies the exact audited bytes.

License texts below are verbatim downloads from commit-pinned official family upstreams or the official Google Fonts distribution repository. Embedded OpenType `name` records supply the local version, copyright, and license evidence; all distinct records are retained below. The font metadata is evidence about the bundled files, not a claim that their binaries are byte-identical to an upstream release.

Inter and Fraunces license sources use the source commit embedded in the local font version. Fraunces upstream license starts with a 2018 copyright while these font binaries declare 2020; both notices are preserved here without rewriting upstream text. Roboto is **3.015 (2026), OFL-1.1**, as supported by its embedded license URL and the matching official copyright notice; do not substitute the Apache license from older Roboto releases. Special Elite is **Apache-2.0**, as explicitly stated in its embedded records.

Redistribute this directory with the external fonts and retain embedded notices. This inventory addresses font notices only; it does not establish licensing completeness of the rest of the application.
