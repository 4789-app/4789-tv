# TV source icons

These are official [Google Material Symbols Rounded](https://github.com/google/material-design-icons/tree/master/symbols/web) SVG paths, converted without changing their paths into Android VectorDrawable XML. Copyright Google LLC; [Apache License 2.0](LICENSE.txt).

| Source fact or control | Official SVG | App resource |
|---|---|---|
| 4K | [4k](https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/4k/materialsymbolsrounded/4k_24px.svg) | `ic_source_4k.xml` |
| 1080p / HD | [hd](https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/hd/materialsymbolsrounded/hd_24px.svg) | `ic_source_hd.xml` |
| HDR / Dolby Vision claim | [hdr_on](https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/hdr_on/materialsymbolsrounded/hdr_on_24px.svg) | `ic_source_hdr.xml` |
| WEB-DL / WEBRip / Blu-ray release type | [video_file](https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/video_file/materialsymbolsrounded/video_file_24px.svg) | `ic_source_video.xml` |
| Audio format and surround channels | [surround_sound](https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/surround_sound/materialsymbolsrounded/surround_sound_24px.svg) | `ic_source_surround.xml` |
| Cached source | [bolt](https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/bolt/materialsymbolsrounded/bolt_24px.svg) | `ic_source_bolt.xml` |
| Previous / Next episode | [skip_previous](https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/skip_previous/materialsymbolsrounded/skip_previous_24px.svg), [skip_next](https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/skip_next/materialsymbolsrounded/skip_next_24px.svg) | `ic_source_skip_previous.xml`, `ic_source_skip_next.xml` |
| Season / episode picker | [expand_more](https://raw.githubusercontent.com/google/material-design-icons/master/symbols/web/expand_more/materialsymbolsrounded/expand_more_24px.svg) | `ic_source_expand_more.xml` |

The generic vectors accompany exact text labels; an HD symbol alone does not assert 1080p, and a video-file symbol alone does not assert WEB-DL. Official Dolby Vision and Dolby Atmos artwork is available from [Dolby Newsroom](https://news.dolby.com/en-WW/assets/), but logo use requires a Dolby agreement. The [HDR10+ certification mark](https://hdr10plus.org/) also has separate logo licensing. This app uses factual labels with the generic vectors until approved brand artwork is provided.
